# Projetos do Curso | Portfólio de Aprendizado

Bem-vindo(a) ao meu repositório de projetos!

Este espaço foi criado para reunir os projetos desenvolvidos durante meu curso e servir como portfólio do meu aprendizado na área de desenvolvimento web. Aqui registro minha evolução, pratico conceitos importantes e organizo aplicações construídas com diferentes tecnologias do front-end, back-end e banco de dados.

## Objetivo

O objetivo deste repositório é apresentar, de forma organizada, os projetos que venho desenvolvendo ao longo dos estudos. Cada projeto representa uma etapa do meu aprendizado, com foco em praticar lógica, estruturação de páginas, integração com banco de dados, criação de interfaces responsivas e desenvolvimento de aplicações web.
