## Sobre

Esta pasta reúne meus prompts e modos de uso para trabalhar com copilotos de IA durante estudos, desenvolvimento de projetos e organização do raciocínio técnico.

A proposta é usar a IA de forma mais intencional: não apenas pedir respostas prontas, mas escolher o modo certo para cada momento do aprendizado.

Aqui eu separo os prompts em cinco modos principais:

```text
Ask   -> entender
Plan  -> planejar antes de agir
Edit  -> mudar código
Agent -> executar tarefas maiores com autonomia
Study -> aprender de forma ativa
```

---

## Mapa dos Modos

| Modo | Ideia principal | Melhor momento para usar |
| --- | --- | --- |
| **Ask** | Entender com clareza | Quando tenho dúvida sobre conceito, erro ou tecnologia |
| **Plan** | Pensar antes de executar | Antes de criar uma funcionalidade ou projeto |
| **Edit** | Alterar código com foco | Quando preciso corrigir, melhorar ou adaptar algo |
| **Agent** | Delegar uma tarefa maior | Quando a tarefa envolve várias etapas |
| **Study** | Aprender participando | Quando quero estudar, praticar e revisar meu raciocínio |

## Como Usar

1. Escolha o modo que combina com seu objetivo.
2. Abra o arquivo correspondente.
3. Copie o prompt base.
4. Adapte com o contexto do projeto, tecnologia ou dúvida.
5. Use a resposta da IA como apoio para pensar, construir e aprender melhor.

### Exemplo rápido

```text
Modo: Plan

Quero criar uma tela de login usando PHP, MySQL, Bootstrap e JavaScript.
Antes de escrever código, me ajude a planejar:
- arquivos necessários;
- estrutura do banco;
- validações;
- fluxo do usuário;
- cuidados de segurança.
```

## Guia Rápido

### Ask

Use quando quiser entender algo com calma.

Ideal para:

- explicar conceitos;
- entender erros;
- comparar tecnologias;
- revisar assuntos;
- transformar temas difíceis em exemplos simples.

### Plan

Use antes de começar a desenvolver.

Ideal para:

- dividir tarefas;
- organizar etapas;
- prever arquivos necessários;
- pensar em banco de dados;
- evitar começar o código sem direção.

### Edit

Use quando já existe código e a mudança está clara.

Ideal para:

- corrigir bugs;
- melhorar funções;
- ajustar layout;
- refatorar trechos pequenos;
- adicionar funcionalidades específicas.

### Agent

Use quando a tarefa for maior e tiver várias etapas.

Ideal para:

- criar uma funcionalidade completa;
- revisar uma pasta ou projeto;
- organizar arquivos;
- investigar problemas;
- executar uma sequência de melhorias.

### Study

Use quando o foco for aprender de verdade.

Ideal para:

- praticar com exercícios;
- responder perguntas guiadas;
- revisar explicações;
- testar entendimento;
- receber feedback sobre seu raciocínio.

## Prompt Base

```text
Você será meu copiloto no modo [MODO].

Meu objetivo é: [descreva o que você quer fazer ou aprender].

Contexto:
- Tecnologia: [PHP, CSS, JavaScript, Bootstrap, MySQL, Node.js...]
- Nível atual: [iniciante, intermediário...]
- Projeto ou assunto: [descreva o projeto]

Siga o comportamento do modo escolhido:

Ask:
Explique com clareza, exemplos e passo a passo.

Plan:
Organize um plano antes de qualquer implementação.

Edit:
Foque em mudanças objetivas no código existente.

Agent:
Execute a tarefa em etapas, com autonomia e atenção ao resultado final.

Study:
Me ajude a aprender de forma ativa, fazendo perguntas, propondo exercícios
e revisando meu raciocínio.
```
